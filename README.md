steam 환경에서 테스트하였으며 그외에는 실행유무가 불확실합니다.

###   설치방법

     ** 방법 1. 원클릭 자동 설치 (가장 추천하는 방법!)**
1. 압축을 푼 폴더에서 'Install_Patch.bat' 파일을 더블 클릭하여 실행합니다.
2. 게임 설치 폴더 확인 안내가 나타납니다:
   - [Enter] 키를 누르면 자동으로 감지된 게임 폴더에 바로 설치됩니다.
   - [2]를 입력하면 마우스로 폴더를 선택할 수 있는 [찾아보기] 창이 열립니다.
   - [3]을 입력하면 설치 경로를 콘솔에 직접 입력할 수 있습니다.
3. 자동으로 원본 백업, 한글 패치 복사 및 세이브 호환성 점검이 완료됩니다!
###   설치방법 2
    ** 방법 2. 간편 수동 설치**
1. 본 압축 파일의 압축을 풉니다.
2. 압축을 푼 폴더 안에 있는 3개의 항목
   - [Config.exe]
   - [Language] 폴더
   - [Resources] 폴더
   를 복사(Ctrl+C)합니다.
3. 오버로드 게임이 설치된 폴더(Overlord.exe가 있는 곳)에 붙여넣기(Ctrl+V)하고
   "대상 폴더의 파일 덮어쓰기"를 선택합니다.
   (기본 Steam 경로: C:\Program Files (x86)\Steam\steamapps\common\Overlord)
   
   끝입니다! 덮어쓰기만으로 100% 한글 패치가 완료됩니다.

★ 게임 내 필수 설정 (자막 켜기) ★
- 게임 실행 후 메인 메뉴의 [옵션(Options) -> 오디오(Audio)] 메뉴로 이동하여
  [자막(Subtitles)] 항목을 반드시 '켬(On)'으로 설정해 주세요!
  (오버로드 1은 기본값이 '자막 꺼짐'이므로 켜야 음성 자막이 한글로 나옵니다.)
