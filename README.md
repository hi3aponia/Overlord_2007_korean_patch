# Overlord (2007)  한글 패치

Windows 전용 한글패치 입니다.

Geminai 3.8 flash를 이용해서 만든 AI 한글패치입니다.


###   한글화 내용 요약
1. **스토리 및 퀘스트 대사 100% 완역**
   - 본편 전체 33개 챕터, 서브 퀘스트, NPC 대사 전면 한국어화
   - 미니언 조언가 놀(Gnarl)의 상황별 대사 202종 및 퀘스트 목표 158종 완역
2. **시스템 및 UI 100% 한글화**
   - 메인 메뉴, 옵션 설정, 대장간 제련소, 영지/던전명, 인게임 HUD
   - 키보드/마우스 및 게임패드(XBox 360/XInput) 조작 가이드 팝업 한글화
3. **고해상도 한글 전용 TTF 폰트 내장**
   - 11,172자 한글 유니코드를 온전히 지원하여 글자 깨짐 및 누락 없음
4. **버그 수정 및 안정성 향상**
   - [프로필 버그 픽스] '새 프로필 생성' 시 `system_rpk@generic_M`이 출력되던 식별자 오류 수정 (`[확인]` 버튼 복구)
   - [창 모드 픽스] `Config.exe`에서 창 모드 선택 시 글자가 깨지던 문제 수정
   - [세이브 호환성] 한글 윈도우 환경에서 프로필 생성 시 튕기던 비ASCII 세이브 경로 문제 자동 점검 및 해결
5. **편의 기능**
   - 원클릭 자동 설치 및 자동 원본 복구 지원
   - 자동 경로 감지 외 마우스로 원하는 폴더를 선택할 수 있는 폴더 찾아보기(GUI) 기능 탑재

###   설치방법

     ** 방법 1. 원클릭 자동 설치 (가장 추천하는 방법!)**
1. 압축을 푼 폴더에서 'Install_Patch.bat' 파일을 더블 클릭하여 실행합니다.
2. 게임 설치 폴더 확인 안내가 나타납니다:
   - [Enter] 키를 누르면 자동으로 감지된 게임 폴더에 바로 설치됩니다.
   - [2]를 입력하면 마우스로 폴더를 선택할 수 있는 [찾아보기] 창이 열립니다.
   - [3]을 입력하면 설치 경로를 콘솔에 직접 입력할 수 있습니다.
3. 자동으로 원본 백업, 한글 패치 복사 및 세이브 호환성 점검이 완료됩니다!

    ** 방법 2. 간편 수동 설치**
1. 본 압축 파일의 압축을 풉니다.
2. 압축을 푼 폴더 안에 있는 3개의 항목:
   - [Config.exe]
   - [Language] 폴더
   - [Resources] 폴더
   를 복사(Ctrl+C)합니다.
3. 오버로드 게임이 설치된 폴더(Overlord.exe가 있는 곳)에 붙여넣기(Ctrl+V)하고
   "대상 폴더의 파일 덮어쓰기"를 선택합니다.
   (기본 Steam 경로: C:\Program Files (x86)\Steam\steamapps\common\Overlord)
   
   끝입니다! 덮어쓰기만으로 100% 한글 패치가 완료됩니다.

★ 게임 내 필수 설정 (자막 켜기) ★
- 게임 실행 후 메인 메뉴의 [옵션(Options) -> 오디오(Audio)] 메뉴로 이동하여
  [자막(Subtitles)] 항목을 반드시 '켬(On)'으로 설정해 주세요!
  (오버로드 1은 기본값이 '자막 꺼짐'이므로 켜야 음성 자막이 한글로 나옵니다.)
